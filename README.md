# Adal Works

Сайт adalworks.kz — статичный сайт на GitHub Pages (ветка `main`, папка `/root`). Без бэкенда, без сборщиков на стороне GitHub.

## Структура

| Путь | Что это |
| --- | --- |
| `index.html` | Главная |
| `zhk/` | Уборка ЖК для ОСИ и УК |
| `biznes-centr/` | Бизнес-центры и офисы |
| `parking/` | Механизированная уборка паркингов |
| `aula/` | Территория круглый год и снег |
| `i18n/<страница>.js` | Тексты RU / KZ / EN для каждой страницы (`window.ADAL_I18N`) |
| `script.js` | Общий скрипт: язык, меню, форма расчёта, WhatsApp-ссылки |
| `styles.css` | Общие стили |
| `sitemap.xml`, `robots.txt`, `404.html`, `CNAME` | Служебные файлы |
| `_build/` | Генератор страниц (Jekyll не публикует папки с `_`) |

## Как менять тексты и страницы

HTML-страницы, `i18n/*.js` и `sitemap.xml` **генерируются** — правьте не их, а исходники:

- `_build/content.py` — тексты новых блоков и подстраниц, каждый ключ: `(ru, kz, en)`;
- `_build/legacy-home.json` — тексты прежних блоков главной (обучение, работы, объекты, о компании, сертификаты);
- `_build/build.py` — разметка страниц.

После правки запустите из корня репозитория:

```bash
python3 _build/build.py
```

и закоммитьте изменённые файлы. Нужен только Python 3, без зависимостей.

## Языки

- Главная по умолчанию отдаётся на казахском (`data-default-lang="kz"`), подстраницы — на русском (`data-default-lang="ru"`).
- Язык браузера и выбор пользователя (localStorage) переключают тексты на лету.
- Параметр `?lang=ru|kz|en` в ссылке принудительно задаёт язык (удобно для рекламы: `https://adalworks.kz/zhk/?lang=ru`).

## Форма расчёта стоимости

- 3 шага: объект → параметры (зависят от типа объекта) → контакты.
- Данные никуда не отправляются: по кнопке «Отправить» собирается текст и открывается WhatsApp (`wa.me/77003330999`) с готовым сообщением. Клиент сам нажимает «Отправить» в WhatsApp.
- Если в адресе есть `utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content`, `gclid` или `yclid`, они запоминаются на время сессии и добавляются в конец сообщения строкой `ref: …`.
- Телефон проверяется: казахстанские номера приводятся к виду `+7 XXX XXX XX XX`, другие страны — с `+` и кодом.

## Локальный просмотр

```bash
python3 -m http.server 4173
```

Откройте http://localhost:4173/ (подстраницы — http://localhost:4173/zhk/ и т. д.).
