# Adal Works

Landing site for adalworks.kz (GitHub Pages).

Статичный лендинг для GitHub Pages.

## Локальный просмотр

Откройте `index.html` в браузере или запустите простой сервер из этой папки:

```bash
python3 -m http.server 4173
```

## Публикация на GitHub Pages

Загрузите содержимое этой папки в репозиторий и включите GitHub Pages для ветки `main`, папка `/root`.
